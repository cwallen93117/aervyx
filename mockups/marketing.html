Tracking infrastructure

Coverage where the
thermals take you.

Two complementary technologies ensure no pilot goes dark — even in remote mountain terrain without cellular.

📶

Cellular Tracking

The Aervyx pilot app streams GPS over 4G/LTE. Any smartphone, zero extra hardware, background-optimised battery usage.

  • 2–5 second update interval over cellular
  • Works with any modern smartphone
  • Background tracking — active while flying
  • Auto-fallback to mesh when signal drops
  • Battery-optimised position reporting
🔗

Meshtastic Mesh Networking

Off-the-shelf Meshtastic LoRa devices form a self-healing ground relay network. Ground nodes pipe pilot positions back to the Aervyx cloud via any internet-connected node.

  • LoRa range: 10–50 km per node in open terrain
  • Self-healing mesh — nodes relay for each other
  • Works with off-the-shelf Meshtastic hardware
  • MQTT ingest pipeline to Aervyx cloud
  • Ideal for remote ridge and alpine sites

GAP-aligned formulas

Uses the GAP2021 formula family — the same model as FAI Cat 1 events. Configure nominal distance, time, launch, and minimum distance per task.

Provisional → Official

Live provisional scores update as tracks arrive. Once the window closes, the director confirms official results — full audit log retained throughout.

SHA-256 evidence chain

Every IGC upload is fingerprinted and stored immutably. Original files are never mutated — full traceability for protests and federation records.

Open source

Aervyx is fully open source.

The entire platform — backend, frontend, scoring engine, and tracking pipeline — is released under the Apache 2.0 licence. Read it, run it, contribute to it, or self-host it. No strings attached.

🔓

Apache 2.0 Licence

Free to use commercially, modify, and distribute — with or without source. No copyleft obligations. No "open core" bait-and-switch. Everything is in the repo.

🏠

Self-Host for Free

Deploy the full Aervyx stack on your own infrastructure using Docker Compose. Perfect for federations wanting complete data sovereignty — no subscription required.

Community Driven

Built by pilots and developers in the free-flight community. Contributions welcome — scoring formulas, hardware integrations, translations, and bug fixes.
