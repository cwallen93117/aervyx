# FlightComp Platform Product Requirements

## Objective

Deliver a self-hosted scoring MVP for hang gliding and paragliding competitions.

## Phase 1 Goals

- Admin and pilot authentication
- Event management
- Pilot import and maintenance
- Turnpoint upload and validation
- Map-based task builder
- Scoring configuration
- IGC upload and immutable evidence storage
- Task scoring and results views
- Auditability for scoring actions

## Explicit Deferrals

- Live tracking
- Mobile apps
- Meshtastic integration
- MQTT ingest
- Replay and device linking
- Provisional live scoring
