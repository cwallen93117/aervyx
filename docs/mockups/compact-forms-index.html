Compact Form Layout Mockups

These previews are based on a Claude review pass and focus on moving many labels to the left of inputs, reducing input widths, and compacting form-heavy pages without changing the live app yet.

Main mockup index

What we’re testing

The current dashboard stacks most labels above the fields, which costs a lot of vertical space. These five options explore different ways to compact Events, Tasks, Scores, Settings, and Admin forms while keeping them readable.

No app code was changed for this request. These are preview-only HTML files.

Claude direction

Claude’s top recommendation was a horizontal label-input row system with deliberate input widths. It also suggested fieldset clusters as the strongest alternative if we want more grouping and wayfinding.
