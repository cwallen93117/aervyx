What this preview set is trying to fix

The dashboard works, but the visual hierarchy is weak in a few places. Tabs can read like plain labels, section headers do not separate content strongly enough, and dense workflows such as task details or scoring operations use more vertical space than they need.

This preview set explores a shared theme language with stronger separators, clearer tab affordance, tighter spacing, and a more deliberate admin-product look without changing backend behavior.

Common theme rules

Stronger tabs Cleaner spacing Clearer card hierarchy Map-friendly overlays Consistent action colors

Theme directions

Each page uses the same three directions so you can pick one family and then apply it consistently.

Option A: Conservative Cleanup

Keeps the current product feeling familiar, but gives tabs and section headers more contrast and organizes dense forms into cleaner rows.

Option B: Modern Product UI

Pushes stronger panel framing, more obvious tabs, richer soft backgrounds, and a more deliberate application-shell aesthetic.

Option C: Compact Operations

Optimized for denser workflows and quick scanning. Best for scorekeeping and task editing where vertical space matters more than decorative breathing room.

Page groups

Each page file contains all three options side by side with representative content.

Tasks

Focuses on stronger section separation, condensed task details, and a cleaner relationship between task metadata, turnpoints, and the map.

Scores

Focuses on making the tabs actually read like tabs, clarifying Scoring Operations vs Results Portal, and improving table hierarchy.

Admin

Focuses on clearer separation between Platform Users and Site Settings, stronger grouping, and tighter vertical rhythm.
