Tracking infrastructure

Coverage where the
thermals take you.

Two complementary technologies ensure no pilot goes dark — even in remote mountain terrain without cellular.

📶

Cellular Tracking

The Aervyx pilot app streams GPS over 4G/LTE. Any smartphone, zero extra hardware, background-optimised battery usage.

  • 2–5 second update interval over cellular
  • Works with any modern smartphone
  • Background tracking — active while flying
  • Auto-fallback to mesh when signal drops
  • Battery-optimised position reporting
🔗

Meshtastic Mesh Networking

Off-the-shelf Meshtastic LoRa devices form a self-healing ground relay network. Ground nodes pipe pilot positions back to the Aervyx cloud via any internet-connected node.

  • LoRa range: 10–50 km per node in open terrain
  • Self-healing mesh — nodes relay for each other
  • Works with off-the-shelf Meshtastic hardware
  • MQTT ingest pipeline to Aervyx cloud
  • Ideal for remote ridge and alpine sites
Meshtastic mesh tracking

Off-grid coverage for
every flying site.

Meshtastic LoRa devices form a self-healing radio mesh that works where cell towers don't. Affordable, solar-powered, and purpose-built for remote terrain.

🏆

Competition Safety

Real-time pilot positions for safety directors and retrieve teams. SOS alerts relay instantly through the mesh — even in valleys with zero cell signal. Every pilot visible, every second.

🪂

Free Flight Clubs

Install a solar-powered node at your club's launch and LZ. Every member with a Meshtastic device is automatically tracked — no subscriptions, no cell plans, no recurring costs.

⛰️

Remote Sites

Mountain launches, desert thermals, coastal ridges with no coverage — LoRa reaches 10-50 km per hop in open terrain. The mesh fills gaps that cellular simply can't.

💲

Affordable Hardware

Complete Meshtastic nodes cost $20-40. Solar-powered and weatherproof options exist for permanent outdoor installation. No monthly fees, no SIM cards, no data plans.

🚗

Retrieve Vehicles

Mount a node on each retrieve vehicle. Drivers stay visible on the tracking map and relay positions for pilots overhead — turning every car into a mobile mesh repeater.

📍

Landing Zone Routers

Leave a fixed node at the LZ before you launch. It acts as a relay point for your flight — capturing your positions and forwarding them through the mesh to the cloud.

How it works

Each pilot carries a small LoRa radio that broadcasts GPS positions. Nearby nodes relay the signal hop-by-hop until it reaches any internet-connected node, which bridges positions to the Aervyx cloud via MQTT. The mesh is self-healing — add or remove nodes and coverage adapts automatically.

GAP-aligned formulas

Uses the GAP2021 formula family — the same model as FAI Cat 1 events. Configure nominal distance, time, launch, and minimum distance per task.

Provisional → Official

Live provisional scores update as tracks arrive. Once the window closes, the director confirms official results — full audit log retained throughout.

SHA-256 evidence chain

Every IGC upload is fingerprinted and stored immutably. Original files are never mutated — full traceability for protests and federation records.

Open source

Aervyx is fully open source.

The entire platform — backend, frontend, scoring engine, and tracking pipeline — is released under the Apache 2.0 licence. Read it, run it, contribute to it, or self-host it. No strings attached.

🔓

Apache 2.0 Licence

Free to use commercially, modify, and distribute — with or without source. No copyleft obligations. No "open core" bait-and-switch. Everything is in the repo.

🏠

Self-Host for Free

Deploy the full Aervyx stack on your own infrastructure using Docker Compose. Perfect for federations wanting complete data sovereignty — no subscription required.

Built by a Pilot

Created by Charles Allen, President of USHPA, for the free-flight community. Features like SOS alerting, bulk IGC import, and mesh safety are built from real flying experience. Contributions welcome — scoring formulas, hardware integrations, and bug fixes.
